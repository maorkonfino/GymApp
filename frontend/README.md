# 🏋️ Frontend - מערכת ניהול אימונים

אפליקציית React מודרנית לניהול הרשמות אימונים בחדר כושר.

## 🎨 תכונות העיצוב

### ✨ עיצוב מודרני
- **Dark Mode** - ממשק כהה ומרשים
- **Gradient Effects** - אפקטים צבעוניים וחדשניים
- **Smooth Animations** - אנימציות חלקות ומקצועיות
- **Responsive Design** - מותאם מושלם למובייל, טאבלט ושולחן עבודה

### 📱 אופטימיזציה למובייל
- תצוגה מותאמת לכל גדלי מסך
- כפתורים גדולים ונוחים למגע
- טקסט קריא בכל הגדלים
- אנימציות מהירות וזורמות

### 🎯 קומפוננטות ראשיות

#### 1. **Header** - כותרת עליונה
- לוגו BEAST והאוניברסיטה העברית
- פרטי משתמש
- כפתור התחברות

#### 2. **NavigationCards** - כרטיסי ניווט
- הרשמה לאימון (כחול-תכלת)
- כל האימונים שלי (כחול)
- תוכנית האימון (סגול)
- מעקב התקדמות (ירוק)

#### 3. **DateSelector** - בורר תאריכים
- תצוגה שבועית
- ניווט בין שבועות
- בחירת תאריך
- אינדיקטור לתאריך הנבחר

#### 4. **DayView** - תצוגת יום
- כותרת עם תאריך
- כפתור הרשמה לאימון
- תצוגה של אימונים ביום

## 🛠️ טכנולוגיות

- **React 18** - ספריית UI
- **TypeScript** - שפת תכנות מתקדמת
- **Vite** - Build tool מהיר
- **Tailwind CSS** - עיצוב מודרני
- **Lucide React** - אייקונים
- **date-fns** - ניהול תאריכים

## 🚀 התקנה והפעלה

### התקנת תלויות
```bash
npm install
```

### הפעלה בסביבת פיתוח
```bash
npm run dev
```

האפליקציה תיפתח ב: http://localhost:3000

### בניית פרודקשן
```bash
npm run build
```

### תצוגה מקדימה של הבנייה
```bash
npm run preview
```

```
│   ├── main.tsx             # נקודת כניסה

│   └── types.ts             # הגדרות TypeScript

├── index.html               # HTML ראשי

├── tailwind.config.js       # הגדרות Tailwind
```


## 📱 Responsive Breakpoints

- **Mobile**: < 640px
- **Tablet**: 640px - 1024px
- **Desktop**: > 1024px

## ♿ נגישות

- תמיכה מלאה ב-RTL (עברית)
- כפתורים עם גודל מינימלי של 44x44px
- ניגודיות גבוהה
- תמיכה במקלדת
- ARIA labels

## 🔄 אינטגרציה עם Backend

האפליקציה מתחברת ל-Backend דרך:
- `VITE_API_URL` - כתובת ה-API (ברירת מחדל: http://localhost:3001)

## 📝 הערות פיתוח

- כל הקומפוננטות בנויות עם TypeScript
- שימוש ב-Functional Components עם Hooks
- עיצוב מבוסס Tailwind CSS
- אנימציות CSS מותאמות אישית
- מותאם למובייל ראשית (Mobile First)
